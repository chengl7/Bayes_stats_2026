# Data for the final assignment (synthetic)

All files are **invented for teaching**. They are not real measurements. Each problem has its own file, and no problem uses another problem's data.

| File | Problem | One row is | Columns |
|---|---|---|---|
| `p1-free-throws.csv` | 1 | one free-throw attempt with the new technique, in order | `attempt`, `made` (1 = scored) |
| `p2-help-desk-calls.csv` | 2 | one day at the help desk | `day`, `hours_open`, `calls` |
| `p3-ice-cream.csv` | 3 | one day at the ice-cream kiosk | `day`, `temperature_C` (maximum), `weekend` (1 = Saturday or Sunday), `sales` (ice creams sold) |
| `p4-restaurant-reviews.csv` | 4 | one restaurant | `restaurant`, `reviews`, `thumbs_up` |
| `p5-driving-test.csv` | 5 | one learner | `learner`, `lessons`, `age`, `family_practice` (1 = also practised with a family member), `passed` (1 = passed at the first attempt) |
| `p7-bakery-demand.csv` | 7 | one weekday at the bakery | `day`, `demand` (customers who wanted a sourdough loaf) |

Problem 6 has no data file: you simulate the data yourself.
