# In-class scores by group

**Bayesian statistics for PhD researchers · Aalborg University · 2026**

Each group is scored **0–4** at the end of every course day, for how actively it worked: the exercises, the question set and the peer review (see [grading.md](grading.md) for the descriptors). Every member present that day gets the group's score. Effort and thinking count, not being right.
