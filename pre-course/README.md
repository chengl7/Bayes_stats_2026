# Pre-course refresher

Self-paced preparation for the course. It is not graded and nothing is submitted.

**Open one notebook:** [pre-course-refresher.ipynb](pre-course-refresher.ipynb). It contains all the explanations, exercises and hints, and uses R's built-in data, so there are no other files to open.

1. Install the software with [the installation guide](../installations.md): Miniconda, then the `bayes` environment, then JupyterLab with the **R (bayes)** kernel.
2. Start JupyterLab from the activated environment, open `pre-course/pre-course-refresher.ipynb`, and select **R (bayes)**.
3. Work through the parts in order. Run a cell with **Shift+Enter**.
4. Check your answers in [pre-course-refresher-solutions.ipynb](pre-course-refresher-solutions.ipynb) after trying each task yourself.

| 1 | R essentials |

| 4 | Simulation and a first likelihood |
| 5 | Your own research question |
| 6 | Self-check: questions to bring to Day 1 |
