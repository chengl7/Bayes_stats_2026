Course materials for the 5 ECTS PhD course, 9–17 November 2026, 08:45–16:00.

**Lecturers:** Lu Cheng and Ege Rubak, Department of Mathematical Sciences, Aalborg University
**Contact:** luch@math.aau.dk · Moodle course 2862

**Course page:** the GitHub Pages site for this repository (or open `index.html`).

## Start here

1. Install the software: [installation guide](installations.md) (Miniconda, R, CmdStan, the tidyverse and JupyterLab in one environment, `bayes`). The [course logistics and setup slides](course-logistics-and-setup.pdf) summarise it.
2. Work through the [pre-course refresher](pre-course/README.md) (self-paced, with worked solutions), or download [pre-course-refresher.zip](pre-course-refresher.zip).
3. Before each course day, download that day’s student pack, unzip it and open the notebooks in JupyterLab with the **R (bayes)** kernel.
